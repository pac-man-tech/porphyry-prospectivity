Predicting Porphyry Copper Deposit Occurrence from Public Geoscience Data

Study area: Arizona, USA (Porphyry Cu-Mo belt)

This repository contains code, notebooks, and documentation for reproducing the Mineral Prospectivity Mapping study.

Reproduction instructions
- Create and activate the conda environment: `conda env create -f environment.yml`
- Activate: `conda activate arizona-porphyry`
- Install pip requirements (if needed): `pip install -r requirements.txt`
- Open notebooks in `notebooks/` and follow the numbered workflow.

Repository structure
See the project root for `notebooks/`, `src/`, `data/`, `reports/`, and `docs/`.
